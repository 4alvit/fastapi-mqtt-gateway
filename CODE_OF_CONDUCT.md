# Code of conduct

This policy applies to project issues, pull requests, reviews and other project spaces. Treat people respectfully; criticize technical work and behavior without personal attacks. Harassment, discrimination, threats, unwanted sexual attention, disclosure of private information and deliberate disruption are unacceptable. Maintainers follow the same standards.

The maintainer may remove abusive content, restrict participation or exclude a participant, considering severity and recurrence. Explain the decision to the affected person when safe, protect reporters' privacy and allow a request for reconsideration with new evidence.

Report concerns through a private contact method the maintainer has made available. Sensitive conduct concerns must not be posted in public issues, including requests that would identify a reporter. If no private contact is published, use GitHub's private platform-abuse reporting when applicable; a project-specific confidential intake must be established before accepting other sensitive conduct reports. This project has one primary maintainer and cannot promise independent adjudication of a complaint about that person. GitHub's platform reporting process remains available for platform abuse. Vulnerabilities use the separate private process in [SECURITY.md](SECURITY.md).
