# Code of conduct

This policy applies to project issues, pull requests, reviews and other project spaces. Treat people respectfully; criticize technical work and behavior without personal attacks. Harassment, discrimination, threats, unwanted sexual attention, disclosure of private information and deliberate disruption are unacceptable. Maintainers follow the same standards.

The maintainer may remove abusive content, restrict participation or exclude a participant, considering severity and recurrence. Explain the decision to the affected person when safe, protect reporters' privacy and allow a request for reconsideration with new evidence.

Send confidential conduct reports to [alvit.work@gmail.com](mailto:alvit.work@gmail.com), including the repository name and the information needed to understand the concern. Do not post personal details, private evidence or requests that identify a reporter in public issues. The primary maintainer reviews reports privately, protecting confidentiality as far as practical. This project has no independent moderator, including for complaints about the maintainer. GitHub's private platform-abuse reporting remains available for platform abuse. Report security vulnerabilities through the separate process in [SECURITY.md](SECURITY.md).
